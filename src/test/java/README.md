# 자동차 경주 1,2단계

## 구현 기능 목록

### Car (자동차)
- 자동차는 이름을 가진다
- 랜덤값이 4 이상이면 전진한다
- 랜덤값이 3 이하이면 멈춘다

### RacingGame (경주 게임)
- n대의 자동차가 참여할 수 있다
- 주어진 횟수 동안 경주를 진행한다
- 경주 완료 후 우승자를 구할 수 있다
- 우승자는 한 명 이상일 수 있다

## 테스트
- 랜덤값이 4 이상이면 전진하는지 검증
- 랜덤값이 3 이하이면 멈추는지 검증
- 각 자동차의 position과 우승자를 출력하여 로직이 잘 작동하는지 검증
- 경주 완료 후 우승자가 한 명 이상인지 검증
- 우승자가 전체 참가자 수를 넘지 않는지 검증
